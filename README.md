# 初言口语 V4 · 自然拼读、邪修语法与1126句口语练习

这是面向零基础中文学习者和小学生的本地英语口语应用。V4 新增自然拼读、系统语法闯关和舒缓拼写反馈音，并把这些能力与原有生活口语课程连接起来。

新增学习路径包含 **17 个单元、90 个微课、540 道练习**：第一单元用 10 课从字母音、短元音、CVC 拼读学到音节与重音；其余 80 课覆盖 A0–B2 日常口语核心语法。每课依次使用场景开门、搭骨架、变形术、抓虫找茬、中文秒转和张嘴就说，不要求先背音标或语法定义。

当前可见内容为 **80 门课、1126 个不重复句子**：

- 日常口语精选：44 课、880 句。句子来自允许复用的 Tatoeba 中英语料，按 44 个生活场景重新筛选和编排；每句保留作者、两个原句编号及链接。
- 官方情景对话：30 课、198 句。收录美国国务院 *Everyday Conversations: Learning American English* 的全部 30 组对话，保留人物和轮次，并配有独立制作的简体中文译文。
- 零基础热身：6 课、48 句。为初言项目独立编写的基础内容。

项目没有复制句游英语的付费题库、音频、图片、文案、商标、源码或私有接口。课程来源、许可和校订原则见 [课程来源与校订说明.md](课程来源与校订说明.md)。

## 在这台电脑上启动

macOS 独立版安装后，双击桌面的“初言英语”即可。应用会自动打开默认浏览器，无需 Node.js、终端、账号或付费 API。安装版包含运行环境、依赖及 Kokoro/Whisper 模型，可离线运行。

学习期间保持“初言英语”应用运行；退出应用会停止本地服务。请固定使用同一个浏览器，学习进度保存在该浏览器的本地存档中。

可编辑项目也能直接双击 `启动.command`，或在项目目录运行：

```sh
npm start
```

然后打开 **http://localhost:4173**。本地服务只监听 127.0.0.1，不提供公开部署或账号系统。

## 课程与口语流程

- 课程页：按教材来源、入门/基础/进阶、六大生活类别筛选；可搜索中文、英文、课程名和句子。
- 短句口语：显示英文和中文，支持遮住英文后看中文开口，也可“跟读完成”自评记录。
- 连续对话：显示当前说话人；从第二句开始会保留上一位角色的英文和中文，便于接话训练。
- 逐句来源：Tatoeba 课程可展开查看英文作者、中文句对作者、原句编号、链接和 CC BY 署名。
- 朗读与录音：Kokoro 在本机生成英音/美音朗读；Whisper 在本机识别录音，并用文字对齐显示相符词、漏词和错词。

此次交付按用户选择**没有使用真实麦克风**。合成语音送入本机识别模型的离线测试已通过。首次自己录音时，浏览器会请求 localhost 的麦克风权限；录音只发送给这台电脑上的本地服务。

## 四种练习方式

- **口语**：跟读、中文提示复述、录音识别、逐词差异和自评完成。
- **听写**：中文提示与逐词输入；忽略英文大小写和标点，支持错后提示。
- **拼图**：选择打乱的词块组成原句，支持撤销、清空和自动判定。
- **学习**：按完整表达理解句子；原有 48 句另有逐词音标、释义和句子成分讲解。

## 拼写反馈音

设置中可选择“舒缓木质、清脆机械、安静轻触、关闭”，并调整音量。默认音量为 90%，按键主音经过动态压缩后更响、更饱满，同时限制叠加音的尖峰。字母、空格、删除、拼对单词、整句正确、错误、拿起词块和撤回词块各有独立反馈。声音由项目使用 Web Audio 在本机实时合成，没有提取或复制参考网站音频。

口语录音支持 0.35 秒以上的短句，适合 “Thank you.”、“Welcome home.” 等快速表达；录音太短、没有输入设备、权限未开启或识别接口异常时会显示对应原因。

文字“识别一致度”只比较识别结果与原句，不能代替音素、重音、语调或流利度评分。噪音、口音和识别模型误差都会影响结果。

## 语音模型

| 功能 | 本地模型 | 说明 |
| --- | --- | --- |
| 英语朗读 | Kokoro 82M v1.0 q8 | 美式男声、美式女声、英式女声、英式男声 |
| 英语识别 | Whisper tiny.en q8 | 识别录音并返回逐词时间位置 |
| 口语反馈 | 本项目文字对齐逻辑 | 标记相符、漏词、错词和额外词 |

这些模型与参考网站的私有模型无关，也不包含其童声或声线。模型和运行环境许可见 [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md)。

## 学习记录与备份

答错会立即进入复习；答对后按连续正确次数安排 1、3、7、14、30 天后的复习。跟读完成计为“自评记住”，统计页会明确显示。收藏句子、单词本、学习时间、错题和当前进度都保存在浏览器本地。

备份页支持导出和导入 JSON。换浏览器、换端口、使用无痕窗口或清除网站数据会产生新的本地存档空间，需要先导出旧记录再导入。

## 在另一台电脑运行源码

需要 Node.js 22 或更新版本。macOS 双击 `启动.command`，Windows 双击 `启动.bat`。首次运行依赖安装需要联网；“含语音模型”压缩包已附带模型缓存。

```sh
npm ci
npm start
```

删除 `models` 后，可联网运行 `npm run setup-models` 重新准备模型。不能直接双击 `index.html`，因为朗读与识别需要本机服务。

从 GitHub 克隆源码后，可执行：

```bash
npm ci
npm run setup-models
npm start
```

仓库不提交 `node_modules` 和约 129 MB 的模型缓存；依赖由 `package-lock.json` 固定，模型由 `setup-models.mjs` 按第三方许可重新准备。
